# API Endpoints

Abaixo estão os principais grupos de endpoints da API:

*   **/api/v1/auth**: Autenticação e geração de tokens JWT.
*   **/api/v1/users**: Gerenciamento de usuários.
*   **/api/v1/brands**: Operações CRUD para marcas de veículos.
*   **/api/v1/cars**: Operações CRUD para veículos.
*   **/health_check**: Verificação de saúde da aplicação.
